# 棋弈台 · 五子棋大模型评测

一个**纯静态**的五子棋评测页面：把任意大模型接进来下棋，支持人机对战、双模型对战（单局 / 三局两胜），对局结束显示获胜方。
不需要后端、不需要构建，浏览器打开即用，密钥只存在你自己的浏览器里。

- 在线地址：`https://xiaogui-666.github.io/gomoku-llm-arena/`
- 也可以直接下载 `index.html` 双击打开（本地调用受浏览器同源策略影响，建议用上面的在线地址）

## 两种玩法

| 模式 | 说明 |
| --- | --- |
| **人机对战** | 你执黑或白，另一端接任意模型（或内置离线引擎） |
| **模型对战** | 两个模型互相对局，支持**单局定胜**和**三局两胜**（每局自动交换先后手） |

对局结束弹出结算：显示获胜方、执子颜色、总手数；三局两胜额外给出总比分。

## 用法

1. 选「对手模型」预设，或选「自定义」自己填。
2. 填**模型名称 / API 地址 / 密钥**，点「测试连接」确认可用。
3. 点「开始对局」或「开始对战」。

模型对战里 A、B 可填不同厂商，互相对打。

### 一条链接带走配置

页面支持网址参数预填，适合把配置发给别人或存成书签：

```
.../?base=https://apihub.agnes-ai.cn/v1&model=agnes-3.0-flash&key=你的密钥
```

打开即自动填入人机对战与对战 A/B 三处，随即写入 localStorage，并立刻把密钥从地址栏清除（不会留在历史记录里）。

## 语言模型为什么能下棋

每回合把 15×15 局面渲染成 ASCII 图（`X` 黑 / `O` 白 / `.` 空），配上坐标规则（列 A–O、行 1–15）、决策优先级和严格输出格式 `MOVE: H8`：

1. 我是否能立刻连成 5 子 → 直接赢
2. 对手是否 4 连、下一手成 5 → 必须堵
3. 对手是否活三 → 优先封堵
4. 否则做自己的活三活四、抢中心

回复做多层容错解析（`MOVE: H8`、`H8`、`{"row":8,"col":8}`、`(8,8)`、`8H` 都认）；
下到已有棋子或输出乱掉时，把原因回传让模型重试一次，仍不行则由内置引擎兜底落子，对局不中断（日志标黄提示）。
默认还会附上引擎算出的 Top5 候选点，弱模型棋力会明显提升，可在高级参数里关掉做纯净评测。

## 关于直连与 CORS

页面是静态的，浏览器**直接**请求你填的接口，不经任何中间服务器。
若厂商接口未开放跨域（CORS），浏览器会拦截，页面会明确提示——先用「测试连接」验证。

## 其他

- **离线也能玩**：选「内置引擎 · 离线」，无需密钥，强度可调。
- **配置记忆**：模型、地址、密钥保存在浏览器 localStorage，不会随请求外发。
- **移动端**：单列布局、棋盘自适应，落子采用「先选中、再确认」两步，禁用浏览器点击高亮。
- **字体**：思源宋体（Noto Serif SC），加载失败时回退到系统宋体。
